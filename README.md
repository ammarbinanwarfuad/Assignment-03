# Rinterio - Interior Design Portfolio Website

Rinterio is a modern, responsive interior design portfolio website that showcases elegant barn house designs and interior design services. The website combines rustic charm with contemporary sophistication, featuring a clean and intuitive user interface built with Tailwind CSS and DaisyUI.

## 🌟 Features

### Main Sections

1. **Navigation Bar**
   - Responsive navigation with logo and menu items
   - Mobile-friendly dropdown menu
   - Search and cart icons
   - "Book Consult" call-to-action button

2. **Hero Banner Section**
   - Eye-catching banner image
   - Compelling headline about barn house design
   - Descriptive text about the design philosophy
   - "View Details" call-to-action button

3. **About Us Section**
   - Introduction to Rinterio's design philosophy
   - Two service categories:
     - **Commercial**: Modern commercial spaces with rustic elements
     - **Residential**: Thoughtful residential designs that transform houses into homes
   - Visual representation with building images

4. **Work Process Section**
   - Four-step process explained:
     - **Concept**: Clear design concepts blending innovation with practicality
     - **Design Process**: Collaborative design approach
     - **Supervision**: Expert supervision throughout projects
     - **Budget Planning**: Budget planning without compromising quality

5. **Portfolio Section**
   - Showcase of latest projects
   - Commercial and residential project examples
   - Image galleries with project details
   - "View Details" links for each project

6. **Client Reviews Section**
   - Testimonials from satisfied clients
   - Client photos and credentials
   - Six different client reviews showcasing trust and satisfaction

7. **Contact Form Section**
   - Contact form with background image
   - Fields for:
     - First Name
     - Last Name
     - Email Address
     - Phone Number
     - Message
   - "Send Mail" button for form submission

8. **Footer Section**
   - Company branding
   - Navigation links
   - "Book Consult" call-to-action button
   - Company description

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Custom styling (via style.css)
- **Tailwind CSS**: Utility-first CSS framework (via CDN)
- **DaisyUI**: Component library built on Tailwind CSS (via CDN)

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A web server (optional, for local development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ammarbinanwarfuad/rinterio.git
```

2. Navigate to the project directory:
```bash
cd rinterio
```

3. Open `index.html` in your web browser:
   - Simply double-click the file, or
   - Use a local web server (recommended):
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js (http-server)
     npx http-server
     ```

4. Access the website:
   - If opened directly: `file:///path/to/rinterio/index.html`
   - If using a server: `http://localhost:8000`

## 📝 Customization

### Changing Colors
Edit the Tailwind configuration in `index.html` (lines 40-61) or modify `tailwind.config.js` to change the color scheme.

### Adding Content
- Update text content directly in `index.html`
- Add new images to the `assets/` folder
- Modify styles in `style/style.css` or add Tailwind classes

### Modifying Layout
- Adjust Tailwind utility classes in HTML
- Modify grid layouts and flex containers
- Update responsive breakpoints as needed
